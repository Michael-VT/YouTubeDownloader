# 🎬 YouTube Downloader

Скачивает с YouTube **видео (mp4)**, **аудио (mp3)** и **текстовую транскрипцию** (по субтитрам) — на выбор или всё сразу. Два интерфейса:

- **CLI** — `download.py`, консольный инструмент на Python;
- **Веб-интерфейс** — `web_server.py` (Flask) + `web_ui.html` (JS в браузере): прогресс-бар, журнал загрузок, список файлов со ссылками на скачивание.

![YouTube Downloader](Screeshot/YouTubDownloader.png)

Языки интерфейса: **English, Русский, Українська, Português, Deutsch, Français**.

Лицензия — **MIT**: использование бесплатно, без ограничений (см. [LICENSE](LICENSE)).

## Быстрый старт

```bash
git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# вариант 1 — консоль: видео максимального качества + транскрипция
python download.py "https://youtu.be/XXXX" max

# вариант 2 — веб-интерфейс: http://127.0.0.1:8080
python web_server.py
```

Для 1080p+ и конвертации в mp3 нужен **ffmpeg** (см. раздел «Установка» ниже). Всё скачанное и все рабочие файлы (`downloads/`, журналы, очередь ожидания) остаются только на вашей машине — в репозиторий они не попадают (см. «Настройки»).

## Возможности

- 🎥 Видео в максимальном качестве (1080p / 1440p / 4K через DASH-потоки со склейкой ffmpeg), среднее или низкое
- 🎧 Только аудио с конвертацией в mp3 с выбором битрейта (128/192/320 kbps) — удобно для прослушивания в дороге
- 📄 Текстовая транскрипция из субтитров (очищенная от таймкодов и разметки) рядом с медиафайлом или отдельно (режим `text`)
- 🌍 Выбор языка аудиодорожки и субтитров (`--lang ru`, `en`, …); приоритет русской дорожки при multi-language видео
- 🔁 Защита от дублей по типам контента: скачанное в низком качестве видео можно докачать в максимальном, как аудио или как текст (журнал по ID; записи с удалённым файлом качаются заново)
- ⏳ Очередь ожидания: недоступное видео (приватное, удалённое, бот-проверка) ставится в очередь автоматически и скачивается с уведомлением, когда станет доступным
- 📝 Журнал загрузок в двух форматах: `download_log.txt` и `download_log.html`
- 🖥️ Веб-UI: информация о видео до скачивания, живой прогресс, история, скачивание файлов из браузера
- 🌐 Переключение языка интерфейса в CLI и в веб-UI (6 языков, по умолчанию — автоопределение)

Что нового в этой версии — см. [CHANGELOG.md](CHANGELOG.md).

## Установка (локально)

### 1. Требования

- **Python 3.10+** (проверено на 3.12)
- **ffmpeg** — нужен для склейки DASH-потоков (качество выше 720p) и конвертации в mp3. Без него программа работает, но видео ограничено 720p (progressive), а аудио останется в исходном формате (m4a)

### 2. Установка ffmpeg

| ОС | Команда |
|---|---|
| macOS | `brew install ffmpeg` |
| Ubuntu / Debian | `sudo apt install ffmpeg` |
| Windows | `winget install Gyan.FFmpeg` (или `choco install ffmpeg`), затем перезапустить терминал |

Проверка: `ffmpeg -version`

### 3. Клонирование и зависимости

```bash
git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Использование: CLI

### Интерактивный режим

```bash
python download.py
```

Задаст вопросы: ссылка → качество → язык → сохранять ли mp3.

### С аргументами

```bash
python download.py "https://youtu.be/XXXX" max          # видео макс. качества + транскрипция
python download.py "https://youtu.be/XXXX" audio        # только mp3 + транскрипция
python download.py "https://youtu.be/XXXX" text         # только текст (транскрипция)
python download.py "https://youtu.be/XXXX" audio --abitrate 320k
python download.py "https://youtu.be/XXXX" medium --lang en
python download.py "https://youtu.be/XXXX" max --mp3 -o video   # + mp3, папка video/
python download.py "https://youtu.be/XXXX" max --ui-lang de     # интерфейс на немецком
```

| Аргумент | Значение |
|---|---|
| `url` | ссылка на видео (без неё — интерактивный режим) |
| `quality` | `max` / `medium` / `low` / `audio` / `text` |
| `--abitrate` | битрейт mp3 для `audio` и `--mp3`: `128k`/`192k`/`320k` (по умолчанию 192k) |
| `--lang`, `-l` | язык аудио и транскрипции (по умолчанию `ru`) |
| `--mp3` | дополнительно сохранить mp3-дорожку рядом с mp4 |
| `-o`, `--output` | папка сохранения (по умолчанию `downloads`) |
| `--ui-lang`, `-u` | язык интерфейса: `en`/`ru`/`uk`/`pt`/`de`/`fr` |

Язык интерфейса определяется автоматически по локали системы (`LANG`/`LC_ALL`); переопределяется флагом `--ui-lang` или переменной окружения `YTD_LANG`.

Команды очереди ожидания:

```bash
python download.py --check-queue     # проверить очередь и скачать ставшее доступным
python download.py --watch 30        # следить за очередью, проверяя каждые 30 минут (Ctrl+C — выход)
python download.py --queue-list      # показать очередь
python download.py --queue-remove URL
```

Недоступное видео (приватное, удалённое, бот-проверка) добавляется в очередь автоматически; кроме того, очередь автоматически проверяется при каждом запуске.

Полная справка: `python download.py --help`

Результат в `downloads/`:

```
Название видео.mp4                  # видео (или .mp3 в режиме audio)
Название видео.mp3                  # при --mp3 или quality=audio
Название видео [320k].mp3           # аудио с нестандартным битрейтом
Название видео.transcript.txt       # транскрипция из субтитров
```

## Использование: веб-интерфейс

```bash
python web_server.py
```

Откройте **http://127.0.0.1:8080** — интерфейс в браузере:

1. Вставьте ссылку → **«Получить информацию»**: обложка, автор, длительность, доступные разрешения, наличие субтитров, статус («новое» или что именно уже скачано: видео 1080p, mp3, транскрипция)
2. Выберите качество, язык и битрейт mp3 → **«Скачать»**: живой прогресс-бар и консольный лог
3. Внизу — список готовых файлов (скачать прямо из браузера), журнал всех загрузок и карточка очереди ожидания с кнопкой «Проверить сейчас»

Язык интерфейса выбирается селектором 🌐 в правом верхнем углу; выбор запоминается в браузере. Лог скачивания тоже выводится на выбранном языке.

Хост и порт можно поменять переменными окружения:

```bash
HOST=0.0.0.0 PORT=8080 python web_server.py
```

## Настройки

Переменные окружения:

| Переменная | Значение |
|---|---|
| `HOST`, `PORT` | адрес веб-интерфейса (по умолчанию `127.0.0.1:8080`) |
| `YTD_LANG` | язык интерфейса: `en`/`ru`/`uk`/`pt`/`de`/`fr` (переопределяет автоопределение) |

Все опции CLI: `python download.py --help` — качество (`max`/`medium`/`low`/`audio`/`text`), битрейт mp3, язык аудио/транскрипции, папка сохранения, язык интерфейса, команды очереди ожидания.

Файлы, создаваемые во время работы — все исключены из git через `.gitignore` и никогда не покидают ваш компьютер:

| Файл / папка | Назначение |
|---|---|
| `downloads/` | скачанные медиа и транскрипции (меняется через `-o`/`--output`) |
| `download_log.txt`, `download_log.html` | журнал загрузок: защита от дублей + удобная таблица |
| `pending_queue.json` | очередь ожидания недоступных видео |
| `_tmp_*` | временные файлы потоков, удаляются после склейки/конвертации |

## Запуск прямо на GitHub

Статический сайт (GitHub Pages) здесь не подойдёт — нужен Python-бэкенд. Поэтому два рабочих варианта.

### Вариант 1: GitHub Actions (без установки чего-либо)

В репозитории есть workflow `.github/workflows/download.yml` с ручным запуском:

1. Откройте вкладку **Actions** → **Download YouTube video** → **Run workflow**
2. Укажите ссылку, качество (`max`/`medium`/`low`/`audio`/`text`), битрейт mp3, язык контента, язык интерфейса, нужен ли mp3
3. Дождитесь завершения → в сводке запуска появится **artifact `youtube-download`** — скачайте zip с файлами

В репозитории ничего не сохраняется: запуск отдаёт только сам медиафайл (mp4/mp3) в виде недолговечного артефакта (1 день). Скачайте zip из сводки запуска; за транскрипцией и журналом запускайте программу локально.

⚠️ **Ограничения**: артефакт хранится ограниченное время (здесь — 1 день), размер ограничен, и YouTube нередко блокирует запросы с IP дата-центров (ошибка «Sign in to confirm you're not a bot»). Для регулярного использования запускайте локально.

### Вариант 2: GitHub Codespaces (полноценный веб-интерфейс в облаке)

1. Кнопка **Code** → вкладка **Codespaces** → **Create codespace on master**
2. Контейнер настроен через `.devcontainer/devcontainer.json`: Python 3.12, ffmpeg, зависимости — установка запускается автоматически
3. В терминале: `python web_server.py` — порт 8080 пробрасывается автоматически, браузер с интерфейсом откроется сам

Расчёт: бесплатная квота Codespaces для личных аккаунтов GitHub — 120 часов ядра в месяц, чего хватает на эпизодическое использование.

## Журнал загрузок

При каждом скачивании создаётся/дополняется запись:

- `download_log.txt` — машиночитаемый лог (по нему определяется «уже скачано»);
- `download_log.html` — удобная таблица со ссылками.

Дубли отслеживаются по типу и качеству: одно видео можно скачать в нескольких разрешениях, несколькими битрейтами mp3 и как текст. Чтобы перекачать тот же вариант, удалите его строку из `download_log.txt` — или просто удалите файл из `downloads/`: записи без файла на диске качаются заново.

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Видео качается максимум в 720p | Не найден ffmpeg → склейка DASH недоступна. Установите ffmpeg и проверьте `ffmpeg -version` |
| «Sign in to confirm you're not a bot» | YouTube блокирует ваш IP (часто на VPN/дата-центрах). Попробуйте другую сеть или запустите локально |
| mp3 не создаётся, остался `.m4a` | ffmpeg не установлен — конвертация невозможна, сохранён исходный аудиопоток |
| Транскрипции нет | У видео нет субтитров. Автоматические субтитры YouTube тоже поддерживаются, если они включены |
| «Access denied» (403) или «Address already in use» на порту 5000 | Порт 5000 на macOS перехватывает AirPlay (Control Center) — поэтому по умолчанию веб-сервер слушает 8080. Если нужен именно 5000 — отключите AirPlay Receiver (Системные настройки → Основные → AirDrop и Handoff) или задайте другой `PORT` |
| pytubefix ломается после обновления YouTube | `pip install -U pytubefix` — библиотеку активно патчат под изменения YouTube |
| Видео недоступно (приватное/удалённое) | Оно автоматически попадает в очередь ожидания — запустите с `--check-queue` или `--watch` (или нажмите «Проверить сейчас» в веб-UI), и оно скачается, когда станет доступным |
